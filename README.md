# DP-Fuel V2
Hola, jugadores. Hoy presento la nueva versión de mi sistema de combustible para FiveM (Rediseño completo del <a href="https://github.com/DonPlastico/DP-Fuel-V1">DP-Fuel V1</a>). Como desarrollador en constante aprendizaje, he incorporado nuevas mejoras para crear esta versión mejorada. Si necesitas sistemas personalizados para tu servidor, no dudes en contactarme.

<h1>Caracteristicas</h1>
- Tres tipos de combustible: Sin Plomo, Plus y Premium <br>
- Sistema para vehículos eléctricos con estaciones de carga <br>
- Compra de bidones de gasolina para emergencias <br>
- Baterías recargables portátiles <br>
- Interfaz completamente rediseñada y optimizada <br>
- Consumo ultra bajo (0.02-0.06ms) <br>
- Sonidos y animaciones mejoradas <br>
- Compatibilidad total con todos los vehículos <br>

<h1>Manual de instalación</h1>
Descarga el script y metelo donde tengas el resto de scripts. <br>
Añadelo en tu server.cfg como DP-Fuel. (Si le cambias el nombre, dejara de funcionar) <br>
Configuración avanzada disponible en el archivo config.lua <br>
